# 8. Do's and Don'ts for Discussing Data Hosted in the ADRF

You **must protect confidential data** by adhering to the fundamental rule: **Never take any exact number out of the ADRF.** This includes sharing numbers via text, screenshot, or image.

For internal discussions about data that has not yet been exported:

- **Exact Numbers**: Do not state statistics in exact numbers. Discuss these values privately on the P: drive inside the ADRF.

- **Comparing Values**: You may state that one value is more than, less than, or about the same as another, but you cannot state the exact difference.

- **Percentages and Proportions**: Only refer to these values within a 25% range.

If you are unsure about a specific situation, contact support@coleridge.us.
