# ADRF User Guide

The ADRF Onboarding Guide provides new users with the information and instructions needed to successfully access, configure, and begin using [Coleridge’s](https://coleridge.us/) Administrative Data Research Facility (ADRF). Its purpose is to reduce onboarding friction, promote a consistent onboarding experience, and enable users to become productive with minimal support intervention.

> Note: Users may find the following resources helpful:
> - **PASS Portal FAQ**: Provides answers to common questions about Coleridge’s PASS Portal, including application process, eligibility requirements, application status, approvals, and related procedures. The PASS Portal FAQ can be found under **FAQ** in the menu on the left-hand side of **PASS Portal**.
> - **ADRF User Guide**: Provides detailed information on using the ADRF, including system features, technical procedures, operational guidance, troubleshooting resources, and other information relevant to active ADRF users. The **ADRF User Guide** is available to users in **Secure PASS** in their **ADRF Project Workspace**. 

Users are encouraged to consult these resources as needed and contact the ADRF Support Team if additional assistance is required.


## Features  
- Step-by-step onboarding instructions  
- Security and compliance guidelines  
- Data access and usage policies  
- FAQ and troubleshooting
